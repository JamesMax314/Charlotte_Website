# Shop Page Plan

## Key Points

- The shop is a more simplified design compared to the free form WYSIWSG portfolio page.
- Store items will be displayed on a grid as vertical rectangels. To handel images which dont match this aspect ration, the a central rectange cutout ofver the middle of the image will be displayed.
- Below each image will be the Title, price and product type e.g. print or digital download. The name will be in a slightly larger font ant left justified, with the price to the right and the product type below the name in a lighter grey colour and not as big as the name
- When a viewer clicks on a product, it takes them to a product page with more images, therse will display as a large image with other images below to select from or click left and right arrows on the main image to cycle through. to the right of the Image is the Name, type, and image description and a button at the bottom to link to ETSY.
- At the top of the viewer page is a filter and a search box, the filter lets you search by price and product type.
