# New textbox form

- Textboxes should allow rich text including links
- The top of the text box should display all of the format options which should apply to text written with them selected but shouldnt alter already existing text. This allows the artist to have a single text box with Bold and regualr text of varying size and fonts etc.

## Scope

- Every input textbox should get the new treatment including the ones in the WYSIWYG freeform secrtion and the main settings like about and contact.
